{% if current_language == "ja" %} 評価指標の意味 {% else %} What do these metrics mean? {% endif %} {% if current_language == "ja" %}

適合率：あるクラスと予測した画像のうち、 実際にそのクラスだった割合です。

再現率：実際にあるクラスに属する画像のうち、 正しく識別できた割合です。

F1：適合率と再現率の調和平均です。

{% else %}

Precision: among predictions for a class, how many were correct.

Recall: among actual images of a class, how many the model correctly identified.

F1: the harmonic mean of precision and recall.

{% endif %}
